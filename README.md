# 🛒 Amazon Clone (HTML & CSS)

A responsive front-end clone of the Amazon homepage built using pure HTML and CSS. This project replicates the layout, design, and basic structure of an e-commerce website.

---

## 🚀 Features

* 🧭 Navigation bar with search functionality
* 🛍️ Product category sections
* 🎯 Clean and structured layout
* 📱 Responsive design
* 🔻 Footer with multiple sections

---

## 🛠️ Technologies Used

* HTML5
* CSS3
